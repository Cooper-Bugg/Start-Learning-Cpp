# portfolio-apps

Collection of polishable applications intended to become portfolio pieces. Each app is more feature-rich and requires a larger, more opinionated design than the smaller exercises in earlier phases.

## Features

- Fly-fishing log: record outings, GPS coordinates, catches, and exportable summaries.
- Strategy-roulette: small game simulation engine that generates and evaluates strategy permutations.
- Deck-builder backend: card collection and deck building logic with import/export and basic match simulation.

## Learning outcomes

- Apply everything from earlier phases to a full-cycle project: design, implement, document, and polish.
- Write a polished README, usage examples, and at least one end-to-end test or sample dataset.
- Practice making opinionated design decisions and justifying them in documentation.

## Build & run

For each app, provide a CMakeLists.txt or simple Makefile and a main.cpp demonstrating common workflows. Include example input files and sample output in the app's own README.

## Notes

- Treat each app as an independent repo when it grows beyond a prototype.
- When turning these into real portfolio items, consider adding packaging, CLI docs, and a short demo video or GIF.
